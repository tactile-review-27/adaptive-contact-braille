# Anonymous ICRA project page

This folder is a self-contained static site built from the latest available Overleaf Git revision (`5e9ee33`) at build time.

## Publish without breaking anonymity

1. Create a new GitHub account used only for this submission. Do not reuse a personal, lab, university, or prior-paper account.
2. Create a new public repository under that account, without author names, affiliations, acknowledgements, personal domains, or links to identifiable social profiles.
3. Copy this folder's contents to the repository root. Before pushing, inspect every image, video, PDF, and file metadata for author/institutional information.
4. Enable GitHub Pages from the repository's default branch. Do not use an institutional custom domain. A neutral repository name creates a neutral project URL.
5. Do not link the anonymous page from personal/lab pages, social media, arXiv, or a non-anonymous code repository during review. Preserve a clean, non-identifying commit history.

`Paper`, `code`, `video`, citation, author, and institutional links are intentionally omitted for double-blind review. Add them only after the review period ends and the venue policy permits it.
